Transaction Data Analytics

From my data analytics internship at iStudio: I turned raw user records, server logs and exchange-rate data into a clean dataset of 53,899 transactions, then analysed monthly revenue and top customers.

  • Python
  • Pandas
  • NumPy
  • SQL
  • SQLite
  • Regex
  • Matplotlib
  • Jupyter
What I did
  • Processed and validated user and transaction data from multiple sources.
  • Used SQL to find the latest user records and filter active users.
  • Used Python regular expressions to extract structured transaction data from server logs.
  • Cleaned, preprocessed and integrated the data with Pandas.
  • Handled missing exchange-rate values and converted EUR revenue to USD.
  • Built a final integrated dataset of 53,899 transaction records.
  • Analysed monthly revenue trends and the top 5 customers.
  • Created visualizations to communicate the findings.

British Airways Booking Prediction

A Random Forest model that predicts whether a customer will complete a flight booking, built for the British Airways Data Science virtual experience on Forage. It reached 84.91% accuracy on 50,000 booking records.

  • Python
  • Pandas
  • NumPy
  • Scikit-learn
  • Matplotlib
  • Jupyter
What I did
  • Explored a dataset of 50,000 customer booking records.
  • Checked for missing values and duplicates, and applied one-hot encoding to categorical features.
  • Ran exploratory data analysis to find patterns in booking behaviour.
  • Built a Random Forest classifier and evaluated it with accuracy, a classification report, a confusion matrix and cross-validation.
  • Analysed feature importance. The most influential factors were purchase lead, flight hour, length of stay, flight day, booking origin, flight duration, and meal and seat preferences.
